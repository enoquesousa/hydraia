# Academic context / Contexto acadêmico

## International designation

HydraIA is the repository publication of **José Enoque Fernandes de Sousa's
Brazilian Undergraduate Thesis**, originally designated in Portuguese as a
**Trabalho de Conclusão de Curso (TCC)**. Internationally, it may also be
described as a **final-year capstone project for the Computer Engineering
bachelor's degree**.

The expression “Brazilian Undergraduate Thesis (TCC)” is used throughout this
repository because there is no single exact international equivalent. “Bachelor's
thesis” is common in some countries, while “undergraduate thesis”, “final-year
project” and “capstone project” are more familiar in others.

## Version boundaries

This publication deliberately separates three layers:

1. **Delivered thesis:** the immutable PDF submitted to FMU in 2026.
2. **Reproducible repository:** reviewed source code, tests, documentation and
   small audit artifacts prepared for public inspection.
3. **Post-submission work:** model deployment upgrades, corrected measurements
   and operational validations produced after the academic submission.

Post-submission improvements must not be retroactively attributed to the results
reported in the delivered thesis. The [scientific errata](ERRATA.md) is the
authoritative guide whenever these layers differ.

Undergraduate Thesis** e **final-year Computer Engineering capstone project**.

denominação oficial brasileira.
